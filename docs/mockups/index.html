A 워크벤치

SSMS·DataGrip처럼 탐색기, 편집기, 결과 탭, 요약 레일을 한 화면에 놓는 IDE형.

장점
  • 한 화면에서 입력부터 적용까지 끝나 오가는 동작이 적다.
  • 현재 web/ 화면 구성과 가장 가까워 구현이 빠르다.
단점
  • 정보가 빽빽해 처음 보는 사람은 어디부터 읽을지 막막하다.
  • 그래프와 표가 탭으로 나뉘어 둘을 동시에 볼 수 없다.
어울리는 사용자
SSMS를 매일 쓰는 DBA, 개발자.
프로시저
편집기 두 번째 탭(입력), 결과 세 번째 탭(그래프·표).
시안 A 열기

B 영향 리포트 우선

결과를 문장 하나로 먼저 말하고, PR의 Files changed처럼 테이블별 diff 카드로 읽는 보고서형.

장점
  • 결론이 맨 위에 있어 바로 판단하고 공유하기 쉽다.
  • 카드마다 원인 칩과 확신도가 붙어 값 단위로 검토하기 좋다.
단점
  • 그래프가 접힌 보조라 전파 경로의 깊이가 덜 드러난다.
  • 테이블이 많으면 카드가 길어져 스크롤이 늘어난다.
어울리는 사용자
변경을 검토하고 승인하는 리뷰어, 팀 리드.
프로시저
입력 카드의 두 번째 탭(폼), 하단 접이식 가정 패널(그래프·diff).
시안 B 열기

C 그래프 캔버스

전파 그래프가 화면 대부분을 차지하고, 노드를 누르면 서랍에서 before/after 표가 열리는 어두운 캔버스형.

장점
  • 연쇄가 깊고 갈래가 많을수록 구조가 한눈에 보인다.
  • 선 모양, 색, 순서 번호를 크게 보여 도구의 차별점이 가장 잘 드러난다.
단점
  • 노드가 수백 개가 되면 확대, 이동, 접기 같은 조작이 꼭 필요하다.
  • 표를 보려면 노드를 하나씩 눌러야 해 전체 값 훑기가 느리다.
어울리는 사용자
연쇄 구조를 파악하려는 설계자, 발표와 시연.
프로시저
상단 모드 전환(SQL / 프로시저), 왼쪽 떠 있는 폼, 캔버스에 호출 그래프.
시안 C 열기

D 단계 안내

작성, 영향 확인, 적용의 3단계 표시줄. 요약, 그래프, 표 순으로 아래로 읽는 안내형.

장점
  • 순서가 정해져 있어 처음 쓰는 사람도 길을 잃지 않는다.
  • 적용 전에 반드시 영향 확인을 거치게 해 안전 규칙과 잘 맞는다.
단점
  • 능숙한 사용자는 단계 이동이 답답하고 반복 작업이 느리다.
  • 세로가 길어 요약, 그래프, 표를 한 화면에 함께 두기 어렵다.
어울리는 사용자
처음 쓰는 사람, 졸업작품 시연 관객.
프로시저
1단계 두 번째 탭(폼), 2단계 하단 접이식 가정 패널.
