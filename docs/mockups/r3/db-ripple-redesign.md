# db-ripple UI 개선안

## 목표
- DB 관리 도구이므로 **정보는 줄이지 않고, 한눈에 읽히게 정리**한다.
- 위험한 작업(원본 적용)은 오히려 더 신중하게 보이도록 한다.

## 핵심 문제 → 해결

| 기존 문제 | 개선 |
|---|---|
| 상단바에 상태 정보(목업 전용, 목업 상태, 샌드박스, 지문, 잠금…)가 흩어져 있음 | **초록 점 + 한 줄 글씨**(배경 박스 없음)로 통합. 세부 내용은 툴팁으로 이동 |
| 한 줄 요약이 긴 문장이라 읽기 어려움 | **단계 칩**(DELETE → 직접 1행 → FK 3행 → 트리거 0행)으로 흐름을 시각화 |
| 범례/읽는 법이 항상 화면 차지 | **"읽는 법 ?" 팝오버**로 접어 둠 |
| 그래프 도구(맞춤/확대/축소/검색/체크박스)가 제각각 | **한 줄 툴바**로 정리, 줌은 하나의 그룹 컨트롤로 |
| 오른쪽 패널에 표·합계·설명·경고가 같은 무게로 나열 | **큰 합계 숫자(4행)** → 테이블별 막대 → 접이식 체크리스트 순으로 위계 정리 |
| "적용 조건 7개 충족"이 하단 버튼 위에 작게 있음 | 접이식 요약 `적용 조건 7/7`, 펼치면 항목 확인 |
| 하단 "목업 근거" 긴 로그가 항상 노출 | 평소엔 **얇은 한 줄(36px)**, "목업 근거 보기"를 누르면 오른쪽 적용 영역과 **같은 높이(104px)로 확장**되어 경계선이 맞음 |
| 원본 적용이 한 번 클릭으로 가능 | **2단계 확인**(원본에서 4행 삭제, 되돌릴 수 없음 → 삭제 확정) |

## 색 의미 (일관 적용)
- 빨강: 삭제되는 행 / 파괴적 동작
- 파랑: FK 연쇄
- 황색: 트리거 · 추론 (점선)
- 초록: 정상·통과·적용 완료 (상태 표시는 점 + 글씨만, 배경 박스·글로우 없음)

## 애니메이션 (의미 있는 곳에만)
1. **전파 그래프 순차 등장**: 실행 시 DELETE → 직접 삭제 → FK 연쇄 → 트리거 순으로 노드와 선이 그려짐. 영향이 퍼지는 순서를 눈으로 이해하게 하는 핵심 모션.
2. 합계 숫자 카운트업, 테이블별 막대 채움.
3. 트리거 점선이 흐르는 효과 (추론 경로임을 구분).
4. 적용 버튼 → 확인 패널 슬라이드 → 완료 체크 그리기.
5. 팝오버/사이드바/편집기 접힘, 하단 근거 영역 확장 전환. (상태 점은 정적으로 유지: 장식 효과 제외)
6. `prefers-reduced-motion` 설정 시 모션 최소화.

## 유지한 것
- 3분할 구조(탐색기 / 작업 영역 / 결과 패널)
- 쿼리 편집기, 전파 그래프·행 변경 탭, 표로 보기
- 0행 숨기기, 테이블 검색, 다크 테마, 단축키(Ctrl+Enter)
- 모든 수치와 경고·근거 정보 (삭제하지 않고 접거나 위치만 이동)

## 인터랙션
- 좌측 테이블 클릭 → 그래프에서 해당 노드 강조(나머지 흐림)
- 검색 입력 시 일치하지 않는 노드 흐림
- ☰ 버튼으로 탐색기 접기, 편집기 접기/펴기
- "목업 근거 보기/접기"로 하단 영역 확장·축소 (확장 시 오른쪽 하단과 높이 정렬, CSS 변수 `--bh`로 공유)
- 다시 실행 / 샌드박스 새로 고침 → 그래프 애니메이션 재생
